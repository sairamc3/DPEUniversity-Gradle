# Dependency Version

## [🏠](../../../README.md)

- You can specify a version or a range of versions
- range
  - 2.3 or later
  - `implementation("org.company:some-lib:2.3")`
- strict version
  - `implementation("org.company:some-lib:2.3!!")`
- Latest version (a little more performance expensive)
  - `implementation("org.company:some-lib:2.+")`
- SNAPSHOT of 2.7
  - `implementation("org.company:some-lib:2.7-SNAPSHOT")`
- Flexibility to allow various specifications
  - [🌎 Versions](https://docs.gradle.org/current/userguide/dependency_versions.html#sec:single-version-declarations)
